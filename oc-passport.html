    Ayuda: uso, guardado y copias portables

    1. Flujo de trabajo

    Importa una ilustración raster propia (PNG, JPEG o WebP de hasta 10 MB y 25 MP), completa el nombre y los textos del personaje, personaliza los cinco colores, el modo de encuadre (Encajar o Rellenar) y el tema visual (Lavanda claro o Noche violeta), exporta la ficha final en PNG de 1600 × 2000 px y descarga una copia JSON para respaldar tu colección.

    2. Guardado automático en este navegador (IndexedDB)

    OC Passport guarda tus cambios automáticamente en la base de datos local del navegador (IndexedDB) cuando el entorno lo permite. El indicador superior muestra Guardado únicamente cuando la escritura de la revisión actual ha finalizado.

    Importante: este guardado automático depende del navegador, del perfil de usuario y de la ruta exacta desde la que abres oc-passport.html. Mover o renombrar el archivo HTML, limpiar los datos del navegador o abrirlo en otro navegador no garantiza recuperar el guardado anterior. Si el almacenamiento falla o está restringido, la aplicación pasa a Modo temporal y te avisará para que descargues una copia JSON antes de cerrar o recargar.

    3. Copia JSON portable (recomendada para conservar y trasladar)

    El botón Descargar copia JSON genera un archivo autocontenido (formato oc-passport v1) con todos tus personajes, textos, cinco colores, ajustes e ilustraciones normalizadas incorporadas. Al usar Importar copia JSON, los personajes del archivo se validan íntegramente y se añaden a tu colección actual con identificadores nuevos sin sobrescribir los personajes existentes (hasta el máximo de 20 personajes).

    4. Ficha PNG (1600 × 2000 px)

    El botón Exportar PNG descarga una lámina visual de alta resolución lista para compartir, archivar en tu artbook o imprimir. El archivo PNG es una imagen visual final y no contiene datos editables para reimportar la colección.
